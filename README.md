# 愈程 CarePath 在线更新源（carepath-release）

本仓库仅用于「愈程 CarePath」Android 应用的在线升级分发，托管安装包（APK）与版本说明，**不含任何业务代码**。

- 应用：愈程 CarePath —— 直肠癌（含肝等转移）患者家庭治疗管理
- 包名：com.longzai.carepath
- 版本与下载：见 [Releases](https://github.com/lwloong95/carepath-release/releases)
- 源码仓库：私有仓 `carepath`，不公开

## 安装说明

1. 下载最新 Release 中的 `carepath-<version>.apk`。
2. 首次安装时，系统会提示「为当前应用允许安装未知来源应用」，请允许。
3. 安装后打开应用即可；后续版本由应用内「在线升级」自动检测与安装。
